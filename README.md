# 自動車技術 体系ガイド ― エンジンを中心に

自動車業界に就職する人が「現場の会話についていける」レベルの基礎知識を、体系的に身につけるための教材です。
エンジン周り（第2〜8章）を厚めに、駆動系・シャシー・電動化・業界知識までひと通りカバーしています。

## 読み方

- **初めての人**：第1章 → 第2章 → 第3章 の順に読むと、残りの章がスムーズに理解できます。
- **時間がない人**：第1章・第2章・第11章・第12章だけでも全体像はつかめます。
- 各章の最後に **「確認問題」** があります。答えられなければ本文を読み返しましょう。
- 分からない単語は [用語集](13_glossary.md) で引けます。
